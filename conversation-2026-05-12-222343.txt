● 所有内容都在 src/config.js 这一个文件里配置，修改后保存，Vite
  会自动热更新。按你想添加的内容类型分述：

  项目卡片

  在 projectcards 数组里添加新对象：
  { go: "🚀 前往", img: "/img/xxx.jpg", title: "项目名", subtitle: "简短描述",
  text: "展开后的详细描述", url: "https://xxx.com", show: false }
  - go — 按钮文字
  - img — 项目封面图路径或网络地址
  - show: false — 初始不展开描述文字

  技能雷达图

  在 polarChart 里对应添加：
  skills: ['Vue.js', 'React', ..., '新技能'],
  skillPoints: [85, 78, ..., 75],  // 和 skills 一一对应，0-100 分值

  社交链接

  在 socialPlatformIcons 数组添加：
  { icon: "mdi-bilibili", link: "https://space.bilibili.com/xxx" }
  图标名来自 Material Design Icons (https://pictogrammers.com/library/mdi/)。

  打字机文案

  在 typeWriterStrings 数组追加字符串即可：
  "你想展示的格言或句子。"

  个性标签

  在 tags 数组追加：
  '新标签名'

  壁纸

  - PC 静态壁纸 → wallpaper.pic 数组
  - 移动端静态壁纸 → wallpaper.picMobile 数组
  - PC 视频壁纸 → wallpaper.video 数组
  - 移动端视频壁纸 → wallpaper.videoMobile 数组

  每条格式：
  { "title": "壁纸名", "preview": "/img/wallpaper/static/xxx/image-pre.webp",
  "url": "/img/wallpaper/static/xxx/image.png" }
  文件放在 public/img/ 对应目录下即可，也可以用网络直链。

  背景音乐

  修改 musicPlayer：
  musicPlayer: {
    server: 'netease',
    type: 'playlist',
    id: '你的网易云歌单ID'
  }

  标题/头像/颜色/亮度/模糊

  直接改对应字段即可，比如：
  avatar: "/img/新头像.jpg",
  welcometitle: "Hi, I'm 新名字",
  brightness: 90,
  blur: 10,

  总结：修改 src/config.js → 保存 →
  浏览器自动刷新看到效果。需要我帮你实际改一些内容吗？

     为个人主页添加网页端内容编辑面板

     背景

     网站的配置数据（项目卡片、技能、标签、社交链接、打字机文案等）全部硬编码在
     src/config.js 中，网页上无法修改。用户希望在网页上就能编辑这些内容。

     方案概览

     在现有设置对话框中新增第 4 个 tab ——"内容编辑"，通过表单编辑所有 config
     数据，保存到 localStorage，下次打开页面时自动读取并覆盖默认
     config，实现无需改源码即可更新内容。

     数据流

     用户编辑 → localStorage.setItem('leleoConfig', JSON) → app.js mounted()
     检测 localStorage
     → 合并到 configdata (reactive) → 所有子组件自动响应更新

     需要修改的文件

     1. 新建 src/components/tabs/tab4.vue — 内容编辑面板

     这是核心新文件，包含所有配置项的表单：

     - 元数据：title、description、keywords 三个 v-text-field
     - 欢迎标题：welcometitle v-text-field
     - 标签：v-chip 展示 + 添加/删除按钮，用 v-text-field 输入新标签
     - 技能雷达图：每个技能名称+分值成对展示，可添加/删除
     - 社交链接：每行 icon(mdi图标名) + link(url)，可添加/删除
     - 打字机文案：每行一个 v-textarea，可添加/删除
     - 项目卡片：每个卡片含 img、title、subtitle、text、url、go
     六个字段，可折叠编辑
     - 底部声明：statement 多行文本
     - 按钮：恢复默认（清除 localStorage）、取消（关闭 dialog）、确认保存

     遵循现有 tab1.vue 的模式：Options API + emits: ['cancel']

     2. 修改 src/app.js

     - 新增工具函数：loadConfig() 合并逻辑：
     优先级: VITE_CONFIG 环境变量 > localStorage > config.js 默认值
     - mounted() 中：用 loadConfig() 替代直接赋值 configdata
     - tabs 数组中新增：
     { icon: 'mdi-pencil', text: '内容编辑', value: 'tab-4', component: "tab4" }
     - 注册组件：import tab4 from './components/tabs/tab4.vue';
     - 修改 setMainProperty 中多处 this.configdata.xxx
     引用，确保指向合并后的数据（当前逻辑已经正确，因为操作的是
     this.configdata）

     3. 修改 src/App.vue

     - 在 tab3 的条件渲染逻辑中，tab4 不需要特殊处理（与 tab1/tab2 一样，直接走
     <component :is> ）

     4. 新建 src/utils/configStorage.js — localStorage 读写工具

     提供三个方法（保持与 cookieUtils.js 风格一致）：
     - saveConfigToStorage(config) — JSON 序列化后存入 localStorage
     - loadConfigFromStorage() — 从 localStorage 读取并 JSON 解析
     - removeConfigFromStorage() — 清除 localStorage 中的配置

     为什么用 localStorage 而非 cookie

     - cookie 大小限制约 4KB，完整 config（含壁纸数据）远超此限制
     - localStorage 通常 5MB+，足够使用
     - tab1/tab2 的 cookie 逻辑保持不变，不影响现有功能

     响应式更新策略

     不调用 location.reload()，改为：
     1. tab4 保存后 emit 一个 data-updated 事件
     2. app.js 接收事件后，重新调用 loadConfig() 更新 this.configdata
     及所有派生数据（projectcards、socialPlatformIcons、personalizedtags）
     3. 由于 configdata 本身是 reactive 的，所有通过 props 绑定到 configdata
     的组件会自动更新
     4. 不需要刷新页面

     对于 tab1（样式预览），目前用 location.reload()
     也可以保持不动，因为话题分离。

     验证方式

     1. 在浏览器打开 http://localhost:5173/
     2. 点击左侧齿轮图标 → 钥匙图标打开设置
     3. 切换到第 4 个 tab"内容编辑"
     4. 修改欢迎标题为自定义文字 → 点确认 → 观察页面标题是否立即更新
     5. 添加一个新标签 → 点确认 → 观察左侧标签区是否新增
     6. 刷新页面 → 确认修改仍然生效（localStorage 持久化）
     7. 点击"恢复默认" → 确认回到 config.js 的默认值
